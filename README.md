# VSM Shop

Cửa hàng thời trang trực tuyến chính thức của VSM.

**URL**: https://store.vsm.org.vn/

## Phát triển

```sh
npm install
npm run dev
```

## Công nghệ

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (database, auth, storage, edge functions)

## Triển khai

Triển khai trên Vercel với domain https://store.vsm.org.vn/.
